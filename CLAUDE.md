# Ice Hockey Documentation Project

## Purpose
This project is for generating ice hockey documentation by researching and querying the internet.

## Instructions for Claude

### Research approach
- Use WebSearch and WebFetch to find up-to-date information before writing any documentation
- Cross-reference multiple sources when covering rules, statistics, or player/team information
- Prefer authoritative sources: NHL.com, IIHF.com, official team sites, Hockey Reference (hockey-reference.com)
- Always note the date of retrieval for time-sensitive information (standings, statistics, rosters)

### Documentation standards
- Write in clear, plain English accessible to both newcomers and experienced fans
- Structure documents with headers, subheaders, and bullet points for scannability
- Include sources inline or in a references section at the end of each document
- Flag any information that could not be verified or may be outdated

### Output format
- Use Markdown for all documentation files
- Name files descriptively in snake_case (e.g., `nhl_rules_icing.md`, `stanley_cup_history.md`)
- Keep each document focused on a single topic; link to related documents rather than duplicating content

### What to research
When asked to document a topic, search for:
1. Official rules or definitions (from governing bodies like NHL/IIHF)
2. Historical context and notable examples
3. Current relevance (recent rule changes, statistics, records)
