## What this method could not have found

- **Cross-document contradictions.** Each file is internally consistent, so no gate sees a disagreement between files. The 7.5/7.7 sibling problem was found only because a reviewer grepped beyond its own file.
- **Other rules for the same act.** Most fixers and reviewers checked the rules their brief named plus the nearby ones. Twice this wave the whole answer was a rule the brief did not name: CARHA 75(b), and HC 7.7 Interpretation 1.
- **The published Playing principles episodes.** They were synthesised from the scripts before these source fixes. Each script carried the conservative reading, so no episode says something unsafe, but the episodes do not match the new source text word for word.
- **No listening pass.** Nothing here has been checked by ear.
