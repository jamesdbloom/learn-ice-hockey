## ⚠️ THE `md_to_speech.py` TRAP I HAVE BEEN WARNING AGENTS ABOUT IS THE WRONG TRAP

**I told several agents the tool *"ERRORS on a positional argument and writes a 223-byte error file that
greps as a clean render."*** ⚠️ **No such file exists. Measured by the coordinator:**

```
--only positions/switching_positions   → "no markdown found", exit 1, NO output directory
--only switching_positions             → exit 0, 63 chunks
```

⚠️⚠️ **THE REAL TRAP IS THE PIPE, and the gate reproduced it BY ACCIDENT while checking:**

```
md_to_speech.py --only positions/... | tail   → exit 0     ← the failure reads as a pass
md_to_speech.py --only positions/...          → exit 1
```

⚠️ **`cmd | tail` returns the PIPE's exit status, so a loud, correct, non-zero failure is invisible.**
**Same shape as the `npm` shim trap `CLAUDE.md` records — different tool, same silent false pass, and
it generalises to EVERY checker piped to `tail` or `grep` in this repository.**

**The right warning for a brief is: check the CHUNK COUNT is non-zero, and never trust `$?` through a
pipe.**
