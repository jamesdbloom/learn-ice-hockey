# SG38: three tooling fixes (23 October 2026)

No content changed.

- **`scripts/synthesize_style_b.py`**
  - **New `pcm_*` path.** `--format pcm_<rate>` now joins the raw chunks byte for byte and wraps the result as WAV (`-f s16le`, samples copied). Before, the concat demuxer could not open the `.pcm` chunks.
  - **Errors.**
    - Every failure path prints its cause.
    - ffmpeg errors print the stderr tail rather than the first 400 characters.
    - A catch-all prints the traceback.
  - **Argument and key handling.**
    - `.wav` output is required for `pcm_*`, and this is checked before any request is sent.
    - The API key is fetched only when a chunk needs synthesising.
  - **Verification.** Run against the cached Finding More Ice chunks with the network blocked: sample data byte-identical to the hand-joined WAV, 1070.96 s. `--dry-run` output is unchanged for another script.
- **`scripts/check_caption_echo.py`**
  - **What it now checks.** It compares each caption with the prose block **below** its marker as well as above.
  - **Command-line changes.**
    - `--show` accepts a diagram id.
    - The tool accepts paths.
  - **Results.**
    - Above-block output is byte-identical: 25 hits.
    - Below-block: 255 compared, 14 hits, now a plan row to read before any cut.
  - **Testing.** A synthetic test proves a below-echo is caught and a facts block is not compared.
- **`scripts/md_to_speech.py`**
  - **The fix.** A possessive "X's." no longer reads as the single letter "s." in `_rule_number_opens_sentence`. A shared `_POSSESSIVE_END_RE` replaces the duplicate in `_sentence_opens_at`.
  - **Testing.**
    - Self-test passes (302 assertions), including new direct assertions on the helper.
    - A full-corpus render before and after is byte-identical: 40 documents, 2554 chunks. No corpus text hit the bug.
  - **Found along the way.** "U.S." is not treated as an abbreviation; added as a plan row.

Checks: md_to_speech --self-test passes, check_secrets passes, and both edited Python files compile. The reviews were the agents' own verification runs, recorded above. These are tools, so the content gate's D1–D15 do not apply.
