# Problems found

## 1. Section 3 cannot be served by one `##`-level block (blocking)

`## 3. The Named Breakout Options` runs lines 119–242 and contains nine named options, each with setup, read, execution, risk and counter — roughly forty-five extractable facts. Compressing that to six produces meta-facts about the section rather than facts a player can use, and it is precisely the section a reader would scan a fact block for. Worse, any six-fact selection must either name some options and not others (implying a ranking the document explicitly refuses to assert — style guide line 228 forbids inventing one elsewhere in the corpus) or name none.

**Recommendation:** section 3 operates at `###` level, one block per option. A worked example for Reverse is given above and reads well.

## 2. `## A Note on Language` is a glossary and resists the "terse imperative" form

Six of its ten bullets are definitions of terms. "Strong side is the puck's side" is not an instruction, and no label on the approved list makes it one — `Key:` is the least-bad fit and is doing work it was not designed for. A fact block here duplicates a section that is already the document's own extraction layer for vocabulary. If the convention is adopted, this section is a candidate for exemption.

## 3. Two needed labels are missing from the approved list

The approved labels cannot express **"how the opposition defeats it"**, which is a structural element of all nine options in section 3 and the thing requirement 3 most needs preserved. `Risk:` means "what can go wrong when you do this"; a counter means "what makes this unavailable against a given shape". Collapsing a counter into `Risk:` or `Never:` is exactly the flattening the brief prohibits — "the wheel is defeated by a second forechecker on the far side" would become "Never: Wheel", which the document contradicts at line 144.

Likewise **the read** — the condition under which an option is correct — has no label. `Options:` names the choice, not the trigger. Without a `Read:` label, every option fact must be written as an absolute or padded with an inline "when…" clause.

**Recommendation:** add `Read:` and `Countered by:` (or `Beaten by:`) to the approved list before section 3 is attempted.

## 4. 3–6 facts is too tight for four sections, and forces compounding

Compounding is the more dangerous failure of the two: a fact that has to carry a safety override and a positional instruction on one line is no longer scannable, which was the whole point.

## 5. `## Common Mistakes` and `## Key Takeaways` are already extraction layers

Adding fact blocks to these two creates a *third* restatement of the same claims. The style guide's own finding at line 263 is that **"the summary layer is where corrections go to die"** — every critical defect in review round 10 lived in a Key Takeaway or Common Mistakes bullet left behind when its body was fixed. This convention would double the number of places a corrected body fact has to be chased to. That is a maintenance cost paid on every future correction, in exchange for summarising a summary.

**Recommendation:** exempt both sections. If the convention is adopted corpus-wide, write the exemption into the convention rather than leaving it to each writer.

## 6. Numbers extracted into fact blocks shed their owners and qualifications

Style guide lines 214–234 and 273 require that a restated number names its owner and carries its qualification. A one-line fact has room for one or the other, rarely both. Three cases in this document:

- **89% / 20%** (line 48). Safe only because I spent a second fact on the study's own conclusion that possession, not method, is the explanation. A five-fact trim would drop it.
- **Hash marks: four per circle, two feet, 5'7"** (line 27). Owned by `rink_map_and_glossary.md`. My proposed fact cites Rule 1.9 but does not name the owner.
- **Trapezoid geometry** (line 477). Handled correctly, but only because the fact is long enough to carry the never-use-27.8 warning. It is the longest line in the whole proposal.

**Recommendation:** a rule that any fact block line containing a number must either name the owning document or be dropped.

## 8. Requirement 3 held, but only by spending facts on it
